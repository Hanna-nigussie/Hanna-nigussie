### ♡ things i've built

**୨୧ [Voice-to-Voice Farmer Advisor](https://github.com/Hanna-nigussie)** 🌱

An Amharic voice-based AI assistant designed to help Ethiopian farmers access agricultural guidance and market information.

**୨୧ [AI Voice Assistant](https://github.com/Hanna-nigussie/elevenlabs-ai-voice-assistant)** 🎙️

An AI-powered voice assistant exploring speech recognition, conversational AI, and voice generation.

**୨୧ [AI Mock Interviewer](https://github.com/Hanna-nigussie/ai-mock-interviewer)** 🎤

An AI-powered application designed to help users practice interviews and prepare for job opportunities.

**୨୧ [AI Resume Analyzer](https://github.com/Hanna-nigussie/AI-Resume-Analyzer)** 📄

An AI-powered tool for analyzing resumes and supporting job application preparation.

**୨୧ [Face & Emotion Recognition](https://github.com/Hanna-nigussie/Face-and-emotion-recognition)** 🧠

A computer vision project focused on detecting faces and recognizing facial emotions.

**୨୧ [Service Scheduling System](https://github.com/Hanna-nigussie/Service-Scheduling-System)** 📅

A web application for managing appointments and connecting clients with service providers.

**୨୧ [Handy Jobs Hub](https://github.com/Hanna-nigussie/handy-jobs-hub)** 💼

A Flutter application that connects job seekers and employers with authentication and role-based access.
